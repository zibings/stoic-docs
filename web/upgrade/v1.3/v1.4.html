breakingv1.4

CliScriptHelper takes its ConsoleHelper once, in the constructor

Every method on the helper took the same ConsoleHelper as its first argument. Passing it once at construction removes the repetition from every script (stoic-php-io #27). RFC #27

v1.3 · you read this
$ch     = new ConsoleHelper($argv);
$script = new CliScriptHelper('Exporter', 'Writes notes to a file.');

$opts = $script->startScript($ch)->getOptions($ch);
$script->showBasicHelp($ch, 'Nothing to do');
v1.4 · the same call now
$ch     = new ConsoleHelper($argv);
$script = new CliScriptHelper('Exporter', 'Writes notes to a file.', $ch);

$opts = $script->startScript()->getOptions();
$script->showBasicHelp('Nothing to do');
