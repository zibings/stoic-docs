NodeBase

Abstract class to provide contract for all nodes used with the chain system.

since v1.3stableclass

Key and version make a node valid

isValid requires both a non-empty key and a non-empty version, and linkNode silently drops invalid nodes. Set them in the constructor with setKey and setVersion; the values are informational and appear in getNodeList and debug output.

process()

process receives whatever the caller passed to traverse() as $sender and the dispatch by reference. A node should check the dispatch type first with isDispatchOfType and return quietly when it does not apply, because a chain can carry several dispatch types over its lifetime.
