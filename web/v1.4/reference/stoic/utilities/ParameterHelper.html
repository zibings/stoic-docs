ParameterHelper

ParameterHelper to collect and serve parameters as typed values.

since v1.3stableclass

Typed getters coerce, they do not validate

getInt, getFloat, getBool, and getString return their default only when the key is absent. A present value is pushed through the matching sanitizer in SanitationHelper, whatever it looks like: a non-numeric string becomes its length as an integer, an array becomes its count, and only the string true is a true boolean. Check the shape with get first when it matters.

getJson decodes a JSON string held under a key and returns the default when decoding fails.

Checking keys

has, hasAll, and hasAny test key presence only. A key set to an empty string counts as present.

Deriving new helpers

The with* and without* methods return clones; the original never changes. getSource returns the array the instance was built from, before any of those changes.
