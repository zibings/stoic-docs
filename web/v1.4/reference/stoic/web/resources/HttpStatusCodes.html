HttpStatusCodes

Enumerated HTTP status codes.

since v1.3stabletype

Constants are named after the reason phrase (OK, NOT_FOUND, UNPROCESSABLE_ENTITY) and valued with the status number, so new HttpStatusCodes(404) and HttpStatusCodes::NOT_FOUND describe the same status. getDescription returns the phrase, or "Unknown Status Code" for a blank instance. Response accepts either an integer or an instance wherever a status is expected.
