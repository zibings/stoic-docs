Response

Class to supply a semi-structured response to API requests.

since v1.3stableclass

The data can be anything json_encode() accepts, including a model, since BaseDbModel implements JsonSerializable. getStatus returns a blank HttpStatusCodes when none was set, which the front controller sends as no status change, so set one. setAsError sets a message as the data and a status in one call and throws InvalidArgumentException for an unknown status number.
