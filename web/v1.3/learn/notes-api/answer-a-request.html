Lesson 2 of 5 · 10 min

Answer a request from the API

A JSON API in Stoic is a second front controller. It boots Stoic, which knows how to route by verb and pattern, loads every *.api.php file under api/, and hands the request to whichever route matches. Each controller registers its routes in its constructor and returns a Response from each handler; the framework encodes the data and sends the status.

You'll leave able to
  • Rewrite /api/* to one front controller.
  • Register a route with a verb, a pattern, and a callable.
  • Return structured data with a status code.

The route pattern is a regular expression matched against the path after /api/. Keep the anchors, or notes will also match notes/7.

Try it · step 1 of 3

Create web/api/index.php that boots the API singleton, loads every *.api.php file under ~/api, and calls handle().

← Scaffold the siteFinish all 3 steps to continue: Store notes in a table →
<?php

	const STOIC_CORE_PATH = '../../';
	require(STOIC_CORE_PATH . 'inc/core.php');

	use Stoic\Web\Api\Stoic;

	global $Db, $Log;

	$api = Stoic::getInstance(STOIC_CORE_PATH, null, $Log);

	foreach ($api->loadFilesByExtension('~/api', '.api.php') as $file) {
		$class = '\\Api\\' . basename($file, '.api.php');

		new $class($api, $Db, $Log);
	}

	$api->handle();
