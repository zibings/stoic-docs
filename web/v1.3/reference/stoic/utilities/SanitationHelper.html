SanitationHelper

Class SanitationHelper

since v1.3stableclass

Defaults

A new helper registers bool, int, float, and string, backed by the classes in stoic/utilities/sanitizers. The constants on this class name them. json is not registered by default even though JsonSanitizer ships; add it when you want it.

Adding your own

addSanitizer accepts an instance or a class name that implements SanitizerInterface. Anything else is ignored silently. A ParameterHelper built with your helper as its second argument uses the extra sanitizers through its get method's third argument.

Unknown keys pass through

sanitize returns the input unchanged when the key is not registered. Check hasSanitizer if silence would hide a typo.
