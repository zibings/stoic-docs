StringHelper

Class to provide some basic helper methods for working with strings.

since v1.3stableclass

Mutating versus copying

append, replace, toLower, and toUpper change the instance and return nothing. subString and data return plain strings. Use copy before mutating a value you were handed, since PageHelper and BaseDbModel hand out copies for the same reason.

Null is a state

A helper built with no argument holds null, not an empty string. isEmptyOrNull and isEmptyOrNullOrWhitespace treat both the same; find and compare return false on a null store, which is also what strpos() returns for "not found". Compare with === false and === 0.

Joining

join is variadic: the glue first, then the parts. Pass a StringJoinOptions as the first argument with guardGlue true to avoid doubled separators when parts already begin or end with the glue, which is what makes it useful for paths.
