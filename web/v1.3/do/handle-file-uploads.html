Accept file uploads

Read $_FILES through the request, one UploadedFile per file, with the error decoded for you.

When a request carries uploads, hasFileUploads is true and getInput returns the ordinary form fields that came with them. The files themselves come from getFiles.

getFile always returns an array, so an input named attachment[] with three files and an input named attachment with one file are handled by the same loop.

What goes wrong

  • name is whatever the browser sent. Never use it as a path on disk; generate your own file name and keep the original only as data.
  • count counts input names, not files. Three files under one name count as one.
  • A request with uploads never has a JSON body. Send metadata as form fields alongside the files.
